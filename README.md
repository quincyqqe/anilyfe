## What is AniLyfe?

Welcome to **AniLyfe** — a personal anime streaming project I've been building simply because I wanted to make one.

You can check it out at **[anilyfe.vercel.app](https://anilyfe.vercel.app)** and watch anime with a clean interface, no ads, and no unnecessary distractions.

This isn't a commercial project or a business. I started it out of curiosity and wanted to see what I could build on my own.
